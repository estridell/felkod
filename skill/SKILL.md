# felkod

Generated by `skill/generate.py` from `cli/felkod --help`. Do not edit by hand.

```
usage: felkod [-h]
              {status,daemon,ident,faults,jobs,run,read,log,sessions,session} ...

felkod: diagnostics for a BMW E46 (Siemens MS43) over a K+DCAN cable.

Talks to felkodd (the daemon that owns the cable) over a unix socket and starts it when needed.
Every command prints one JSON object: {"ok": true, "data": ..., "warnings": [...]} or
{"ok": false, "error": {"code": ..., "message": ...}}. Exit status 0 = ok, 1 = error, 2 = usage.
Stdlib only.

positional arguments:
  {status,daemon,ident,faults,jobs,run,read,log,sessions,session}
    status              daemon, cable and link state; does not start the
                        daemon
    daemon              start or stop felkodd
    ident               DME identification (IDENT job)
    faults              read stored faults (FS_LESEN), or clear them
                        (FS_LOESCHEN)
    jobs                list the SGBD's jobs, or describe one (arguments,
                        results, comments)
    run                 run one SGBD job; jobs that change the car need
                        --allow-write
    read                run read-only jobs once, or log them for --duration
                        seconds
    log                 background logging session: start, stop, status
    sessions            list logging sessions
    session             inspect a session: show (summary) or query (read-only
                        SQL)

options:
  -h, --help            show this help message and exit
```

## felkod session

```
usage: felkod session [-h] [--limit LIMIT] {show,query} id [sql]

Session database (SQLite, read-only here): samples(id, t, elapsed_s, cycle,
job, ms); readings(sample_id, name, value, text, unit); events(id, t,
elapsed_s, kind, job, detail); meta(key, value); view series(t, elapsed_s,
job, name, value, text, unit). t is UTC ISO 8601 at job start; names are the
SGBD's result names; events.kind is link_lost, still_down, link_restored or
job_error

positional arguments:
  {show,query}
  id
  sql

options:
  -h, --help     show this help message and exit
  --limit LIMIT
```
